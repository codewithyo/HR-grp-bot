Supported bot commands

General
- /start - Start the bot and view the welcome message
- /help - Show the help screen for your role
- /hr - Get profile or group information
- /hstats - Show moderation statistics
- /hmodinfo - View moderator information

Notes and filters
- /notes - List saved notes
- /save <name> <text> - Save a note
- /get <name> - Retrieve a note
- /clear <name> - Delete a note
- /filters - List active filters
- /filter <keyword> <response> - Add a filter
- /stop <keyword> - Remove a filter

Connections and broadcast
- /connections - Manage connected groups
- /connect <chat_id> - Connect PM to a group
- /disconnect [chat_id|all] - Disconnect from a group
- /allowconnections yes|no - Allow or block PM connections
- /hbroadcast - Use in bot DM to broadcast a message to all connected groups or to one specific connected group; the bot will ask you to reply with the message

Moderation
- /hauth <user_id> - Authorize a moderator (Owner)
- /hgrant <user_id> - Grant permissions (Owner)
- /hrevoke <perm|all> <user_id> - Revoke permissions (Owner)
- /hfreeze <user_id> - Freeze a moderator (Owner)
- /hunfreeze <user_id> - Unfreeze a moderator (Owner)
- /hbadge <user_id> <badge> - Set a moderator badge (Owner)
- /hwarnconfig - Configure warning actions (Owner)
- /hban /hkick /hmute /hunban /hunmute - Moderate users
- /hwarn /warns /resetwarns - Manage warnings
- /hdel /hprotect /hunprotect /hcase /happeal - Handle moderation actions

Games
- /ttt - Start a Tic-Tac-Toe match
- /tttleaderboard - View the leaderboard
- /tttmystats - View your game stats
- /tttend - Forfeit the active game
